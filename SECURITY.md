# Security Policy

Please report suspected vulnerabilities privately by email to `khaledaymen850@gmail.com` with the subject `Kessetna security report`.

Do not include real merchant databases, customer information, licence keys, PINs or other sensitive business data in a public GitHub issue. Provide the smallest reproducible example and remove personal or commercial information before sending attachments.

Pilot releases are unsigned and may display an **Unknown publisher** warning. Download installers only from the official Kessetna website or this repository's GitHub Releases, and compare the SHA-256 checksum when authenticity is in doubt.
